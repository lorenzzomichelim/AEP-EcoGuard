# EcoGuard — Painel de Monitoramento Ambiental 🌿
Projeto Interdisciplinar (AEP) desenvolvido para o 3º Semestre de Engenharia de Software - UniCesumar.

## 🎯 Objetivos de Desenvolvimento Sustentável (ODS)
Este projeto atende às diretrizes da ONU para as seguintes metas:
* **ODS 11:** Cidades e Comunidades Sustentáveis
* **ODS 15:** Vida Terrestre

## 🛠️ Tecnologias e Conceitos Aplicados
* **Front-End:** HTML5, CSS3 (Flexbox/Grid) e JavaScript Vanilla.
* **Estrutura de Dados:** Implementação manual de Fila (Queue - FIFO) para processamento de alertas de incêndio.
* **POO:** Modelagem Orientada a Objetos com as classes `Alerta`, `FilaAlertas` e `EcoGuardApp`.
